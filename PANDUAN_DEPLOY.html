1

Buka Workspace & Setup Git

Di workspace ini (Arena), project sudah dibuat di folder /home/user/video_app/. Sekarang kita inisialisasi Git.

Buka terminal di Arena (ikon terminal di sidebar kiri), lalu ketik perintah berikut satu persatu (tap tombol SALIN untuk menyalin):

Masuk folder project:

cd /home/user/video_app

Inisialisasi Git:

git init

Set username & email GitHub (ganti dengan milikmu sendiri):

git config user.email "EMAIL_KAMU@GMAIL.COM" git config user.name "USERNAME_GITHUB_KAMU"

Tambahkan semua file:

git add .

Commit pertama:

git commit -m "feat: Verve AI Video Studio v1.0"

Ganti nama branch jadi main:

git branch -M main
2

Buat Repo Baru di GitHub

  1. Buka github.com/new di HP browser
  2. Isi Repository name: verve-video-studio
  3. Pilih Public (atau Private juga boleh, nanti di Vercel tetap bisa)
  4. JANGAN centang "Add a README", "Add .gitignore", "Add a license" (karena kita sudah punya file)
  5. Klik "Create repository"

Setelah halaman repo muncul, lihat bagian "…or push an existing repository from the command line". Copy 2 baris perintah yang ada di situ (yang mulai dengan git remote add origin dan git push).

Atau pakai template ini — ganti USERNAME dengan username GitHub kamu:

git remote add origin https://github.com/USERNAME_KAMU/verve-video-studio.git git push -u origin main
⚠️ Kalau diminta login/password saat push: gunakan Personal Access Token (PAT), bukan password biasa.
Cara bikin PAT (klik buka)
  1. Buka github.com/settings/tokens/new
  2. Note: verve-deploy, Expiration: pilih 90 days atau No expiration
  3. Centang repo (bagian teratas)
  4. Klik "Generate token", copy token tersebut (hanya muncul sekali)
  5. Saat diminta password di terminal, paste token itu

Jika berhasil, kode kamu sekarang sudah ada di GitHub. 🎉

3

Deploy ke Vercel

  1. Buka vercel.com/new (sudah login dengan GitHub)
  2. Cari repo verve-video-studio → klik Import
  3. Di halaman "Configure Project", scroll ke bagian "Environment Variables"

Kamu perlu masukin 3 environment variable. Isi satu persatu (tulis di kolom KEY dan VALUE, lalu klik Add):

Variable 1:
HCNSEC_API_KEY

Valuenya = API Key dari akun api.hcnsec.cn kamu (paste langsung).

Variable 2:
HCNSEC_BASE_URL

Valuenya =

https://api.hcnsec.cn/v1
Variable 3:
NEXTAUTH_SECRET

Valuenya = random string panjang, copy ini:

verve-ai-studio-2026--secret-key

Klik Deploy — tunggu 1-3 menit sampai ada halaman "Congratulations!" dengan URL seperti verve-video-studio-xxxx.vercel.app. 🎉 Aplikasi kamu sudah ONLINE!

💡 Tap link yang Vercel kasih — kamu sudah bisa pakai aplikasi di HP browser. Supabase belum dipakai tapi aplikasi tetap jalan.
4

Test Aplikasi (tanpa Supabase dulu)

  1. Buka URL Vercel kamu di HP browser
  2. Pilih tab "Slideshow + Spectrum"
  3. Masukkan niche (misal "tips motivasi belajar"), klik Generate Keyword
  4. Lanjut Step 2 sampai Step 5 — klik "Render Video Sekarang"
  5. Video akan ter-render di HP kamu (Chrome Android recommended).
⚠️ Kalau render lambat di HP, coba di PC/laptop — karena rendering dilakukan oleh perangkat kamu sendiri (browser). Server Vercel cuma ngirim halaman + proxy API ke hcnsec.
5

Setup Supabase (untuk simpan project)

Kalau mau fitur "Simpan project" & "History video", kita pakai Supabase. Kalau gak butuh, bisa skip — aplikasi tetap jalan 100%.

  1. Buka Supabase Dashboard
  2. Klik "New Project"
  3. Pilih Organization (biasanya sudah ada default)
  4. Nama project: verve-video-studio
  5. Database Password: buat random (klik icon generate) — catat/simpan password ini (berguna nanti kalau connect DB client)
  6. Region: pilih Singapore (paling dekat Indonesia)
  7. Klik "Create new project" — tunggu 2-3 menit sampai siap
6

Jalankan SQL di Supabase

  1. Dalam project Supabase, klik menu SQL Editor di kiri (icon database)
  2. Klik "New query" (kanan atas)
  3. Hapus SQL default yang ada
  4. Copy semua SQL di bawah ini lalu paste ke editor:
-- Tabel projek video create table if not exists public.projects ( id uuid default gen_random_uuid() primary key, user_id uuid references auth.users(id) on delete cascade not null, title text, niche text, keywords jsonb default '[]'::jsonb, titles jsonb default '[]'::jsonb, slides jsonb default '[]'::jsonb, viz_style text default 'bars', viz_color text default '#ec4899', audio_mode text default 'tts', slide_duration numeric default 3, tts_text text, status text default 'draft', video_url text, created_at timestamptz default now(), updated_at timestamptz default now() ); -- RLS alter table public.projects enable row level security; create policy "Users can read own projects" on public.projects for select using (auth.uid() = user_id); create policy "Users can insert own projects" on public.projects for insert with check (auth.uid() = user_id); create policy "Users can update own projects" on public.projects for update using (auth.uid() = user_id); create policy "Users can delete own projects" on public.projects for delete using (auth.uid() = user_id); -- Storage buckets insert into storage.buckets (id, name, public) values ('videos','videos',true) on conflict (id) do nothing; insert into storage.buckets (id, name, public) values ('images','images',true) on conflict (id) do nothing; -- Storage policy create policy "Public read videos" on storage.objects for select using (bucket_id = 'videos' or bucket_id = 'images'); create policy "Authenticated upload own" on storage.objects for insert to authenticated with check ( (bucket_id = 'videos' or bucket_id = 'images') and (storage.foldername(name))[1] = auth.uid()::text ); -- Trigger updated_at create or replace function set_updated_at() returns trigger as $$ begin new.updated_at = now(); return new; end; $$ language plpgsql; drop trigger if exists trg_projects_updated on public.projects; create trigger trg_projects_updated before update on public.projects for each row execute function set_updated_at();
  1. Klik tombol "Run" (▶️) di kanan bawah — tunggu "Success. No rows returned"
✅ Database & storage sudah siap!
7

Tambah Env Supabase ke Vercel & Redeploy

  1. Masih di dashboard Supabase, buka Project Settings (icon gear di bawah kiri) → API
  2. Copy "Project URL" (yang formatnya https://xxxx.supabase.co)
  3. Copy "anon public" key (yang panjang, mulai dengan eyJ...)

Buka dashboard Vercel kamu → pilih project verve-video-studio → tab Settings → Environment Variables. Tambahkan 2 variabel baru:

Variable 4:
NEXT_PUBLIC_SUPABASE_URL

Valuenya = Project URL yang kamu copy dari Supabase (paste langsung).

Variable 5:
NEXT_PUBLIC_SUPABASE_ANON_KEY

Valuenya = anon public key dari Supabase (paste langsung).

Kedua variabel dicentang untuk semua environment (Production/Preview/Development).

Setelah itu, ke tab "Deployments" di Vercel → klik titik 3 (⋯) di deployment paling atas → pilih "Redeploy" → konfirmasi. Tunggu 2 menit.

🎉 Aplikasi sudah terhubung dengan Supabase. Nanti kalau ditambah fitur login/history/dashboard, datanya akan tersimpan otomatis.

Troubleshooting Umum

🔑 API Key error / 401 / 403

Cek HCNSEC_API_KEY di Vercel → Settings → Environment Variables. Pastikan benar dan saldo akun hcnsec kamu cukup.

🎨 Gambar gagal generate

step-image-edit-2 adalah model gambar premium ($120/1M tokens). Kalau saldo tipis, ganti nama model di file src/lib/types.ts pada baris DEFAULT_IMAGE_MODEL dengan model gambar lain yang ada di akun kamu, lalu git push.

🎬 Text-to-Video gagal

Tidak semua provider mendukung /videos/generations. Cek di dashboard hcnsec apakah ada model video (Kling, Wan, Sora dll), lalu ganti DEFAULT_VIDEO_MODEL di src/lib/types.ts dengan nama model yang tersedia. Jangan lupa git add && commit && push.

📱 Video lambat di HP

Rendering video memakai CPU perangkat kamu. Di HP jadul bisa lambat. Coba di PC/laptop Chrome/Edge untuk hasil MP4 (H.264) yang siap upload YouTube.

🔴 Vercel deploy error

Buka tab "Deployments" → klik deployment yang gagal → lihat log merah di bagian "Build Log". Error biasanya karena env var kurang atau typo. Perbaiki, lalu Redeploy.
