🚀 DEPLOY KE VERCEL SEKARANG

1Setelah klik tombol di atas

Kamu akan dibawa ke halaman Vercel "Import Project" dengan repo kamu sudah terisi otomatis. Kalau diminta login, login dengan akun GitHub (yang sama tadi).

📱 Di HP layar kecil, bagian Environment Variables kadang tersembunyi — scroll ke bawah halaman, cari tulisan "Environment Variables", lalu klik "Expand" atau "Add".

2Isi 3 Environment Variables satu-persatu

Di bagian Environment Variables, masukkan 3 key berikut. Tap tombol SALIN untuk setiap KEY dan VALUE:

Variable 1:

KEY
HCNSEC_API_KEY
VALUE

👉 Ini diisi dengan API Key dari akun api.hcnsec.cn kamu (login ke api.hcnsec.cn, copy API key kamu, lalu paste di kolom value).

Variable 2:

KEY
HCNSEC_BASE_URL
VALUE
https://api.hcnsec.cn/v1

Variable 3:

KEY
NEXTAUTH_SECRET
VALUE
verve-ai-studio-2026-zhoniandre-super-secret-key-9xK3mP7qR
📸 Cara nambahinnya: ketik nama KEY di kolom kiri, paste VALUE di kolom kanan, lalu klik "Add". Ulangi sampai ketiganya terdaftar. Pastikan di dropdown "Environment" tercentang semua (Production, Preview, Development).

3Klik Deploy

Setelah 3 variabel terisi, klik tombol "Deploy" (warna hitam/hijau) di kanan atas. Tunggu 1-3 menit — Vercel lagi build project kamu.

⏳ Jangan tutup halaman selama proses build. Nanti akan muncul layar "Congratulations!" dengan foto 🔥 — itu artinya berhasil!

4Buka aplikasi kamu!

Setelah sukses, Vercel kasih link aplikasi kamu formatnya:

verve-video-studio-xxxx.vercel.app

Klik link itu — aplikasi Verve AI Video Studio sudah ONLINE dan bisa dipakai di HP maupun PC! 🎉

Coba test:

Masukkan niche (misal: "tips produktivitas"), klik Generate Keyword
Lanjut sampai Step 5, pilih style spectrum "Particles", warna pink
Klik Render Video — tunggu, video harusnya bisa di-download

5(Opsional) Hubungkan ke Supabase nanti

Kalau mau fitur simpan project/history, nanti bisa kita setup Supabase. Tapi untuk saat ini aplikasi bisa dipakai penuh tanpa Supabase kok. 👍
